ISLAMABAD MODEL SCHOOL FOR BOYS (I-V) DHOKE MAI NAWAB
Website + Backend — مکمل پیکج
================================================================

کیا نیا ہے؟
- اب یہ Python بیک اینڈ کے ساتھ ہے (server.py) — کوئی اضافی لائبریری
  انسٹال کرنے کی ضرورت نہیں، صرف Python 3 چاہیے۔
- ایڈمن کے لیے محفوظ لاگ اِن (پاس ورڈ)۔
- تمام ڈیٹا SQLite ڈیٹا بیس (data.db) میں محفوظ ہوتا ہے۔
- ایڈمن جو ہوم ورک / امتحان / نوٹس شائع کرے گا، وہ تمام والدین اور
  طلبہ کو ہر ڈیوائس پر نظر آئے گا۔ (پہلے یہ صرف اسی براؤزر میں رہتا تھا)

اپنے کمپیوٹر پر چلانا
----------------------------------------------------------------
1. اس فولڈر کو Extract کریں۔
2. اس فولڈر میں Terminal / CMD کھولیں۔
3. یہ کمانڈ چلائیں:
       Windows:  py server.py
       Mac/Linux: python3 server.py
   (یا Windows پر start_windows.bat پر ڈبل کلک کریں)
4. براؤزر میں کھولیں:
       ویب سائٹ:  http://localhost:8000
       ایڈمن:     http://localhost:8000/admin.html
5. ڈیمو پاس ورڈ:  admin123
   لائیو کرنے سے پہلے لازمی بدلیں — نیچے دیکھیں۔

پاس ورڈ کیسے بدلیں؟
----------------------------------------------------------------
سرور چلانے سے پہلے ADMIN_PASSWORD سیٹ کریں:
       Windows (CMD):  set ADMIN_PASSWORD=آپکا_مضبوط_پاس_ورڈ
                       py server.py
       Mac/Linux:      ADMIN_PASSWORD=your-strong-password python3 server.py

انٹرنیٹ پر فری پبلش کرنا (Render — تجویز کردہ)
----------------------------------------------------------------
Netlify صرف static سائٹ کے لیے ہے؛ بیک اینڈ کے لیے Render جیسی
سروس چاہیے جو Python چلائے۔ اس پیکج میں render.yaml شامل ہے۔

1. یہ فولڈر GitHub پر اپ لوڈ کریں۔
2. render.com پر فری اکاؤنٹ بنائیں > New > Web Service > اپنا
   GitHub ریپو منتخب کریں۔
3. Start Command:  python server.py
4. Environment Variable شامل کریں:
       ADMIN_PASSWORD = آپ کا مضبوط پاس ورڈ
5. Deploy دبائیں — آپ کو ایک لائیو لنک ملے گا، جیسے
   https://imsb-school.onrender.com
   اسی ایک لنک پر ویب سائٹ اور /admin.html دونوں چلیں گے۔

اہم نوٹ
----------------------------------------------------------------
- فری ہوسٹنگ پر ڈیٹا بیس (data.db) سرور restart ہونے پر ختم ہو
  سکتا ہے (Render کے فری پلان میں مستقل ڈسک شامل نہیں)۔ باقاعدہ
  استعمال کے لیے یا تو Render کی paid disk لیں، یا ڈیٹا بیس کو
  کسی مستقل سروس (مثلاً Turso / Supabase) پر منتقل کرنا ہوگا۔
  اسکول کی اصل لانچ سے پہلے یہ فیصلہ کر لیں۔
- حساس طالب علم معلومات (رزلٹ، فیس ریکارڈ وغیرہ) اس سسٹم پر
  شائع نہ کریں — یہ سسٹم صرف ہوم ورک، امتحانی شیڈول، نوٹسز اور
  منظور شدہ تصاویر کے لیے بنایا گیا ہے۔

فائلیں
----------------------------------------------------------------
server.py       بیک اینڈ (لاگ اِن، API، ڈیٹا بیس)
index.html      پبلک ویب سائٹ
admin.html      ایڈمن ڈیش بورڈ (لاگ اِن کے ساتھ)
styles.css      ڈیزائن
app.js          پبلک سائٹ — API سے ڈیٹا لاتا ہے
admin.js        ایڈمن — API سے پبلش / ڈیلیٹ کرتا ہے
render.yaml     Render پر ڈپلائے کی سیٹنگ
Procfile        دیگر ہوسٹس کے لیے اسٹارٹ کمانڈ
.env.example    پاس ورڈ سیٹنگ کی مثال
